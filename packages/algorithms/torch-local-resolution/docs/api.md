# API reference

Everything below is importable from `torch_local_resolution` directly. `estimate_local_resolution` computes a per-shell p-value map from two half-maps by local correlation. It validates its arguments with `ComputeResolutionInput` and calls `compute_resolution`; `compute_correlation` returns the underlying per-shell correlations.
