# API reference

Transformation matrices are generated by the functions in
`torch_affine_utils.transforms_2d` (3x3 matrices) and
`torch_affine_utils.transforms_3d` (4x4 matrices). They act on homogeneous
column vectors, so `A @ B` applies `B` first.

      show_root_heading: true
      show_root_full_path: true
